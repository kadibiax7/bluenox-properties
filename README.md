# Bluenox Properties

Website for Bluenox Properties, a real estate business founded in Nigeria and expanding to the United States.

## View the website

[Open Bluenox Properties on GitHub Pages](https://kadibiax7.github.io/bluenox-properties/). This link becomes available once GitHub Pages deploys the site.

To preview locally, download the repository and open `index.html` in a browser. No build step is required.

## Publish on GitHub Pages

Open [Settings → Pages](https://github.com/kadibiax7/bluenox-properties/settings/pages). Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
